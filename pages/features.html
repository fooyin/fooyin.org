Features

fooyin combines flexible playback and library tools with an interface you can shape around your music.

Playback

  • Playback of all major formats, including FLAC, MP3, MP4, Vorbis, Opus, WavPack, WAV, AIFF, MKA, Musepack and Monkey’s Audio
  • Native support for VGM and tracker/module formats through optional plugins
  • Gapless and bit-perfect playback
  • Playback directly from archives
  • Full CUE sheet support, including embedded cues
  • Internet radio discovery and remote audio stream playback
  • ReplayGain support, including calculation
  • Configurable fades and crossfades for playback transitions
  • DSP chains with built-in and plugin-provided DSPs
  • Waveform seekbar, spectrum and other visualisations
  • Flexible audio output and device configuration

Library, Playlists & Metadata

  • Advanced filtering and search across library and playlist data
  • Standard playlists, dynamic autoplaylists and a playback queue
  • Playlist import and export in M3U and M3U8 formats
  • Library tree and directory browser views
  • Built-in tag editor and metadata management tools
  • Artwork embedding, downloading, viewing, exporting and extracting

Widgets, Scripting & Customisation

  • Fully customisable interface from a blank canvas or preset layouts
  • Lyrics search, editing, syncing and display
  • FooScript for advanced formatting, display logic, queries and autoplaylists
  • Rich text and script formatting across most widgets and views
  • Personalised keyboard shortcuts
  • Extensible plugin system

Integration

  • MPRIS support for desktop controls and media keys
  • Scrobbling with Last.fm, Libre.fm, ListenBrainz and custom services
  • Discord Rich Presence
